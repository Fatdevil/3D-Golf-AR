# Slagpar

Lägg CSV-exporter från launch monitorernas appar här. Varje fil ska innehålla utgångsvärden och launch monitorns egen carry för samma slag. Se `../../README.md` för format, sidofiler och regler.

Mappen är tom tills det finns riktiga exporter. Lägg aldrig in påhittade eller avskrivna siffror här.
